Modelo SARIMA · Pronóstico de series de tiempo

Este tablero consume las lecturas en tiempo real de InfluxDB y proyecta las próximas horas usando un modelo SARIMA entrenado en Google Colab.

  • No es una verdad absoluta: el SARIMA estima basándose en patrones pasados. Si el entorno físico cambia bruscamente (fallas, apagones), la predicción se saldrá de la banda.
  • Vigila la banda de confianza: si el sensor real empieza a medir fuera del sombreado violeta, es señal de que el modelo necesita reentrenamiento.
  • Infraestructura Docker: todo el sistema (FastAPI + InfluxDB + Frontend) está empaquetado y corre en GitHub Codespaces.
